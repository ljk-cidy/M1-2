## 우선 보완

1. 로컬 및 배포 환경의 OpenAI 키를 설정하고, 실제 질문·응답·자동 저장·대화 복원을 검증합니다.
2. Render와 Vercel에 배포하고 실제 프론트·API·Swagger URL을 README에 기록합니다.
3. 실제 서비스의 질문·답변, 데이터 CRUD, 기록 복원 화면을 제출 증빙으로 준비합니다.
4. 평가 페이지 열람 허용 후 실제 항목과 배점에 맞춰 이 표를 다시 대조합니다.

이번 점검은 읽기와 테스트만 수행했으며 실제 DB 데이터나 평가 제출 상태를 변경하지 않았습니다. 102개는 이번 조회 시점의 값이며, 이전 적재 완료 시점의 101개와 구분합니다.
